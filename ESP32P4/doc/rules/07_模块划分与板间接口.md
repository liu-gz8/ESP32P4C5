## 1. 模块划分(三模块)

按你的要求,整机拆成三个物理模块。每个模块只做一件事,接口尽量少且单向。

```
┌───────────────────────────┐         ┌───────────────────────────┐
│  M1 感知模块               │  UART   │  M2 控制模块               │
│  · ESP32-P4(视觉/音频/显示)│◄───────►│  · STM32F407VGT6           │
│  · ESP32-C5(Wi-Fi/BLE/感知)│  3Mbps  │  · IMU(ICM-42688-P)        │
│  · 摄像头 MIPI-CSI         │         │  · 外部 Flash(参数/黑匣子) │
│  · 480x480 MIPI 屏(incell) │         │  · 6 路 PWM + 3 条总线输出 │
│  · 4 麦阵列 + 扬声器       │         │                            │
└──────────┬────────────────┘         └──────────┬────────────────┘
           │ 5V_AUX / GND                        │ 18×PWM + 使能 + 采样
           │                                     │
      ┌────▼─────────────────────────────────────▼────┐
      │  M3 电源驱动模块                                │
      │  · 电池输入、主保险丝、软启动、主开关            │
      │  · 急停硬件回路(常闭,串联舵机使能)            │
      │  · 6.0-6.5V / 25A 舵机降压(独立电机驱动板)     │
      │  · 5V_AUX 降压(给 M1/M2,与舵机域隔离)         │
      │  · 18 路舵机连接器、PWM 缓冲/驱动器             │
      │  · 3× INA226 分组电流采样 + 母线电压采样        │
      │  · 可选:保护监督 MCU(独立切断舵机电源)       │
      └────────────────────────────────────────────────┘
```

### 1.1 模块职责与边界

| 模块 | 唯一职责 | 板上放什么 | 不放在这里 |
|---|---|---|---|
| M1 感知模块 | 看、听、显示、连网 | P4、C5、摄像头、屏、麦阵、功放、本地 3.3V/1.8V/2.8V 电源 | 任何运动决策、任何舵机接口 |
| M2 控制模块 | 运动、安全、实时闭环 | F407、IMU、外部 Flash、本地 3.3V | 大电流功率器件、舵机连接器 |
| M3 电源驱动模块 | 供电、驱动、保护 | 电池、保险丝、软启动、舵机降压、PWM 缓冲、电流采样、舵机插座 | 任何 MCU 逻辑决策(除可选监督 MCU) |

**关键原则**:电源与功率器件全部集中在 M3,任何 MCU 模块都不出现大电流回路。舵机电流不会流过 M1/M2 的地平面。

### 1.2 为什么 P4 和 C5 放同一模块

| 理由 | 说明 |
|---|---|
| 链路最短 | P4↔C5 的 SPI(20-40MHz)走板内短线,不用跨板连接器,信号完整性最好 |
| 时序好管 | 两者要同步复位/同步上电,同板最省事 |
| 结构集中 | 摄像头、屏、麦阵、天线都在同一块板上,整机和结构件配合简单 |
| 射频隔离 | 天线区净空只需在这块板上保证,不会和其他模块的功率走线抢空间 |

**代价**:M1 是整机最贵、最难返修的一块。所以 M1 上的模组建议用**可插拔模组**(而不是裸芯片),方便单独更换与升级。

## 3. 板间连接器

### 3.1 J1:M1 感知模块 ↔ M2 控制模块

| 信号 | 数量 | 说明 |
|---|---|---|
| UART(3.3V) | 2 | P4 与 F407 主链路,3Mbps |
| P4_IRQ | 1 | P4 → F407 事件线 |
| P4_READY | 1 | F407 → P4 就绪握手 |
| P4_RST | 1 | F407 → P4 复位(可选,预留) |
| GND | 4 | 多针并联降阻 |
| **合计** | **9-12** | 建议用 2×6 (12pin) 带防呆 keying |

> M1 与 M2 之间**不传电源**,M1 的电从 M3 直接取(见 J4)。这样 M1 的摄像头/屏电流不会经过 M2 的地平面。

### 3.2 J2:M2 控制模块 ↔ M3 电源驱动模块(关键连接器)

| 信号组 | 数量 | 说明 |
|---|---|---|
| 小腿舵机 PWM | 6 | 3.3V 逻辑,经 M3 缓冲成 5V |
| 总线舵机 A/B/C | 9 | 每条 3 线(TX/RX/DE),经 M3 转半双工总线 |
| SERVO_PWR_EN | 1 | 低有效,由 F407 PE3 控制 |
| ESTOP_STATUS | 1 | 急停回路状态回读(给 MCU 观测) |
| 母线电压采样 | 2 | 电池电压、舵机母线电压 |
| I2C(SCL/SDA) | 2 | 访问 M3 上的 INA226 组 |
| 5V_AUX 输入 | 3 | M3 → M2 供电 |
| GND | 8 | 每个信号组之间有回流地 |
| **预留:CAN** | **2** | 未来扩展(接 CAN1,PD0/PD1) |
| **合计** | **34-36** | 建议 2×18 |

> **总线舵机已从"预留"变为"主用"**:髋与大腿 12 个关节走 BUS_A/B/C 三条半双工总线,小腿 6 个关节保留 PWM。J2 反而比原 18 路 PWM 方案少了 8 针。

### 3.3 J3:M1 感知模块 ↔ M3 电源驱动模块

| 信号 | 数量 | 说明 |
|---|---|---|
| 5V_AUX | 2-3 | P4 峰值约 1.2A + C5 峰值 0.35A + 屏背光 |
| GND | 4 | |
| PWR_EN_M1 | 1 | F407 经 M3 控制 M1 上电(也可由 M3 直接给) |
| **合计** | **7-8** | |

> 屏背光是脉冲负载,建议在 M1 本地做升压与储能,M3 只提供 5V。

### 3.4 J4:M3 舵机插座(对外)

| 输出 | 内容 | 采样与说明 |
|---|---|---|
| PWM ×6 | 小腿 L1-L6 | MG996R,3pin 插座;每 3 路配 1× INA226(共 2 路采样) |
| BUS_A | L1 + L2 的髋与大腿(4 个舵机) | 3 线串接 + 电源;配 1× INA226 |
| BUS_B | L3 + L4 的髋与大腿(4 个舵机) | 同上 |
| BUS_C | L5 + L6 的髋与大腿(4 个舵机) | 同上 |

**分组原则有两层**:电气上按"轨 + 总线"分组便于限流与采样;空间上按腿走线,便于排查"某条腿同时没力"这类问题(总线把一条腿的髋与大腿串在一起,故障定位天然按腿划分)。

### 3.5 J5:人机与安全接口

| 接口 | 说明 |
|---|---|
| 急停按钮 | 常闭回路(M3 上),断线即触发 |
| 主开关 | 机械开关或按键 + 软启动 |
| 充电口 | 按电池方案定(平衡充接口或 XT60 + 外接平衡充) |
| 状态指示 | 电源指示 + 分组故障指示(LED) |

## 4. 电源分配与上电时序

### 4.1 电源域

| 电源域 | 电压 | 最大电流(估算) | 供给 | 隔离方式 |
|---|---|---|---|---|
| VBAT | 9.0-12.6V | 15A 输入峰值 | M3 内部 | 主保险丝 25-30A |
| SRV_PWM | 6.0-6.5V | 10-12A | 6× MG996R(小腿) | 独立降压 + 母线电容,与逻辑域分地 |
| SRV_BUS | 6-8.4V 或 12V(按型号) | 15-20A | 12× 总线舵机(髋、大腿) | 独立轨;若型号支持,可直接用 3S 电池减少一级降压损耗 |
| 5V_AUX | 5.0V | 4A | M1、M2 | 独立降压 + π 型滤波 |
| 3V3_M1 | 3.3V | 3A(P4 1.2A + C5 0.35A + 余量) | M1 本地 | M1 本地降压 |
| 3V3_M2 | 3.3V | 1A | M2 本地 | M2 本地降压 |

**"MCU 独立供电"的落地含义**:M1 与 M2 各有自己的 3.3V 稳压,只在 M3 的 5V_AUX 处共用一个源;舵机的大电流不经过任何 MCU 模块。舵机堵转时,5V_AUX 只会被母线跌落轻微影响,不会把 MCU 拉到复位。

### 4.2 上电时序(必须按序)

```
t0  M3 上电 → 软启动限流 → 5V_AUX 建立
t1  M2 上电复位 → F407 初始化(BSP/时钟/IMU/PWM 外设,但 PWM 输出关闭)
t2  F407 拉高 M1_PWR_EN → M1 上电 → P4/C5 启动 → 自检
t3  M1 置 P4_READY → F407 收到后认为视觉域可用
t4  F407 完成自检 + 收到站立指令 → 拉低 SERVO_PWR_EN 释放舵机电源
t5  F407 把关节缓动到标准站姿
```

| 规则 | 原因 |
|---|---|
| 舵机电源永远最后释放 | 上电瞬间舵机若已带电而 MCU 未初始化,会出现乱跳 |
| PWM 外设初始化完成后再给舵机电 | 目标脉宽已在影子寄存器里,释放瞬间就是目标姿态 |
| M1 掉电不影响 M2 | 视觉域可以单独重启而不摔机器人 |
| 掉电顺序相反 | 先断舵机,再断 M1,最后 M2(由低压检测触发收腿后执行) |

### 4.3 软启动

18× MG996R 的母线电容 4700µF 在 12.6V 满电时,如果不限流,上电瞬间的浪涌会让电池保护板跳闸。

```
浪涌能量估算:E = 0.5 × C × V² = 0.5 × 4700µF × 12.6² ≈ 0.37 J
峰值电流:无软启动时可达数十安培(受内阻限制),持续毫秒级
```

做法:主 MOS 用限流/斜坡启动(例如 20ms 内把栅极电压缓慢拉高),或串一个 NTC + 继电器旁路。**必须实测上电浪涌**(EC-04)。

## 5. 接地、信号完整性与保护

### 5.1 星形接地(关键)

```
     M3 电源模块(唯一接地点 GND_STAR)
        │        │         │
   舵机地 ────┐  │      M1 地
              │  │         │
           M2 地         屏/摄像头地
```

| 规则 | 说明 |
|---|---|
| 舵机回流绝不经过 MCU 地 | 18 路舵机的回流走 M3 上的专用宽铜皮,直接回电池负极 |
| 每个模块的地在 M3 单点汇合 | 避免地环路;若必须跨模块,用多针并联并靠近功率回流的路径 |
| 模拟采样用开尔文接法 | INA226 分流电阻的两端单独走差分对回到采样芯片 |
| 数字与射频区分区 | M1 上 C5 天线区净空,射频地与数字地单点连接 |

### 5.2 PWM 信号质量

| 措施 | 说明 |
|---|---|
| M3 上做 5V 缓冲 | 74HCT245(VIH 2.0V,可被 3.3V 驱动),输出 5V 边沿给 MG996R |
| 串联电阻 | 每路 PWM 在连接器侧串 22-47Ω,抑制反射 |
| 不与大电流平行走线 | PWM 与总线信号线尽量远离舵机电源走线,必要时加地线隔离 |
| 长线束 | 舵机线每 20-30cm 加一个磁环或双绞,降低串扰 |

> MG996R 是模拟舵机,输入高电平门限对 3.3V 逻辑有时处于边缘(部分批次要求 3.0V 以上)。加缓冲器是消除这类"偶发不动作"最省事的做法。

### 5.3 可选:保护监督 MCU(强烈建议)

在 M3 上加一颗小 MCU(如 STM32G030F6P6 / CH32V003),只做四件事:

1. 独立监测舵机分组电流与母线电压
2. 超限时**直接切断舵机电源**(不经过 F407)
3. 心跳:若 F407 超过 500ms 无心跳,自动切断舵机电源
4. 软启动时序与浪涌控制

**价值**:F407 死机、程序跑飞、SWD 调试时挂住,这些情况下软件层的保护全部失效,只有独立硬件监督能救。代价约 10 元人民币与 2cm² 板面积。

是否采用需要你决定(见 §9)。

### 6.3 扭矩校核(2026-09-27 改版:髋+大腿换总线舵机)

三足步态下 3 条腿支撑,单腿负载 ≈ W/3。算法不变(动态系数 2,力臂 大腿 L_ht = 75mm、小腿 L_kt = 50mm,余量目标 1.3):

```
大腿关节需求 = (W/3) × L_ht × 2
小腿关节需求 = (W/3) × L_kt × 2
```

| 关节 | 现役舵机 | 扭矩 | 允许质量(余量 1.3) |
|---|---|---|---|
| 大腿 femur | 总线舵机 25 kg·cm | 2.45 N·m | W ≤ **3.85kg** |
| 小腿 tibia | MG996R 11 kg·cm @6V | 1.08 N·m | W ≤ **2.54kg** |

**瓶颈已从大腿转移到小腿**,整机质量上限从 1.7kg 提升到约 **2.5kg**。完整对比见文档 08 §4.1。

| 结论 | 数值 |
|---|---|
| 当前基线质量 | 约 2.27-2.47 kg(舵机小计增至 1110g) |
| 扭矩允许上限(小腿决定) | 约 2.5 kg |
| **结构设计目标** | **≤2.2 kg**(留出约 10-15% 机械余量) |

**目前的约束(比原方案宽松,但仍需遵守)**:

1. **整机质量目标 ≤2.2kg**:虽然上限提到 2.5kg,但基线估算已到 2.47kg,减重仍是必答题
2. **关节力臂要短**:足端落点尽量在髋关节正下方,直接决定小腿的扭矩需求
3. **步态要温和**:小腿仍是 MG996R,加减速仍需限幅
4. **小腿是新的薄弱环节**:若后续要精确落点或提高负载,优先升级小腿(见文档 08 §5)

> 这张表要在机械设计开始时交给结构工程师,而不是等装配完再发现"抬不起腿"。

### 6.5 电源与续航(估算)

| 工况 | 电流 | 功率 | 续航(3S 4000mAh,44Wh) |
|---|---|---|---|
| 站立不动(仅保持姿态) | 5-8A | 30-48W | 约 55-85min |
| 正常行走 | 8-14A | 48-84W | 约 30-50min |
| 快速行走/负载 | 15-22A | 90-132W | 约 20-30min |
| 峰值(不可能持续) | 25A+ | 150W+ | 由电容与电池放电能力决定 |

> 表中数值**全部是估算,必须实测**(EC-04)。两处不确定:MG996R 的保持电流很高(受力时每个可达 300-500mA),而 12 个总线舵机的保持电流取决于型号与力矩设定(有力矩限制的型号通常比模拟舵机省电,但 25 kg·cm 级的器件本身功耗更大)。**总线舵机的电压轨越接近电池电压,整体效率越高**——这也是希望选 12V 型号的理由之一。

## 7. 机械接口建议

| 项 | 建议 |
|---|---|
| 模块安装 | 三个模块用 M3 铜柱 + 减震垫安装在同一底板或分层结构上 |
| M1 位置 | 摄像头与屏朝前,天线区朝上或朝外,避免被金属件遮挡 |
| M2 位置 | 靠近几何中心,减少线束长度 |
| M3 位置 | 靠近电池,舵机线束尽量短且对称 |
| 线束固定 | 舵机线用扎带固定在结构上,不允许自由晃动(会磨断且引入噪声) |
| 重心 | 电池放在几何中心最低处,整机重心尽量低且居中 |
| 检修性 | M1 用可插拔模组;M3 的保险丝与主开关要能不开壳更换 |

## 8. 升级预留(你要求的"后续可升级")

| 预留项 | 硬件位置 | 升级路径 |
|---|---|---|
| **小腿换总线舵机** | 直接串入现有 BUS_A/B/C(每条再加 2 个节点) | 只换 M3 的舵机插座与线束 + 固件关节驱动映射,控制板不改 |
| 小腿保留 PWM 换数字舵机 | 现有 6 路 PWM 引脚不变 | 仅把 PWM 改成 250Hz 并重跑标定(见文档 02) |
| 小腿加磁编码器 | 6× AS5600,需 I2C 多路复用(TCA9548A) | 见文档 08 §3 方案 A |
| 更多模拟输入 | PD12-PD15、PA0-PA3、PE5/PE6 已空闲 | 足底接触检测、力传感器、温度 |
| CAN 设备 | J2 上的 CAN1(PD0/PD1) | 外接传感器或第二控制板 |
| 屏升级 | M1 的 MIPI-DSI | 换更大分辨率屏只需改配置与背光 |
| 麦克风升级 | M1 的 I2S0(TDM) | 支持到 4-8 麦阵列 |

> **升级路径的关键设计**:换成"6 路 PWM + 3 条总线"后,释放出的定时器与引脚让后续升级几乎不需要改控制板——小腿要加传感器有 ADC 引脚,要换舵机有总线余量。这是这次架构调整的隐藏收益。

## 9. 本文件待确认项

| # | 事项 | 影响 | 建议 |
|---|---|---|---|
| 1 | 是否采用 M3 上的保护监督 MCU | 安全等级与成本 | 建议采用(F407 死机时唯一保护) |
| 2 | 电池是 3S 还是 2S | 舵机降压的发热与效率 | 建议 3S(2S 满电 8.4V 直供会超 MG996R 额定) |
| 3 | **总线舵机型号与工作电压**(6-8.4V 还是 12V) | 决定是否新增一条舵机电压轨,以及整流效率 | 优先选 12V 型号,可用 3S 直供减少一级降压 |
| 4 | **总线分 2 条还是 3 条** | 单点故障范围与接线复杂度 | 建议 3 条(故障时最多影响 2 条腿) |
| 5 | **小腿位置方案**(维持开环 / 加编码器 / 也换总线) | 成本、精度与开发量 | 先做 EC-09 实测再定,详见文档 08 |
| 6 | 舵机线束长度与分组布局 | 压降与噪声 | 机械冻结后定 |
| 7 | 屏的具体型号(触摸控制器) | M1 的 I2C 地址与初始化 | 选屏后确认 |
| 8 | 整机质量目标是否接受 ≤2.2kg | 决定小腿能否继续用 MG996R | 需要你与结构确认 |

## 0. 结论摘要(先看这个)

**大腿换总线舵机:强烈支持,而且这是当前最划算的一次改动。** 它把整机质量上限从 1.7kg 抬到约 2.5kg,并让你现在的 2.2kg 基线方案第一次变得可行(细节见 §4)。

**小腿用自训练模型判断位置:分目标看,一半可行一半不可行。**

| 你的目标 | 可行性 | 原因 |
|---|---|---|
| 知道小腿**是否卡死/失步/断线**(故障判断) | **可行** | 有明确特征:电流、姿态、步态相位的组合异常 |
| 知道小腿**精确角度**(位置估计,用于 IK 闭环) | **不可行** | 见 §2 的可辨识性分析:电流不携带角度信息 |

**建议**:小腿位置问题的正确解法不是模型,而是一颗约 10 元的磁编码器,或者把小腿也换成同系列总线舵机。用自训练模型去替代一个 60 元的传感器,开发成本远高于省下的硬件钱。模型应该去做它擅长的事——**异常检测**——那部分确实值得做,方案见 §5。

## 1. 问题定义(先定判据,再谈方案)

"判断小腿位置"要服务三件不同的事,判据完全不同:

| 用途 | 需要的量 | 精度要求 | 更新率要求 |
|---|---|---|---|
| A. IK 闭环与足端定位 | 小腿绝对角度 | ±1° 以内(足端 ±2mm) | ≥50Hz |
| B. 故障判断(卡死/脱扣/断线) | 布尔量 + 粗略偏差 | 只需 5-10° 的分辨力 | ≥20Hz |
| C. 姿态估计与地形适应 | 小腿角度趋势 | ±3° 可接受 | ≥20Hz |

**先明确你要的是哪一类。** 后面 A 与 B 会走向完全不同的方案。

## 2. 核心:可辨识性分析(为什么"电流到角度"走不通)

### 2.1 MG996R 的结构决定了什么是已知的

MG996R 内部已经有一个位置闭环:电位器测角度,内部电路比较后驱动电机到目标角。所以各量的状态是:

| 量 | 状态 |
|---|---|
| 命令脉宽 u | **完全已知**(我们发的,精度 µs 级) |
| 目标角度 θ_cmd | 已知(由标定表映射) |
| 实际角度 θ_actual | **未知**,且 θ_actual = θ_cmd - e |
| 误差 e | 未知,由负载、摩擦、间隙、齿轮磨损、供电电压共同决定 |

**关键洞察**:正常工况下 e 很小(典型 0.5°-2°)。也就是说,**我们本来就知道小腿大概在哪**。真正未知的不是"角度",而是"误差有多大"。

### 2.2 为什么电流不能反推角度

伺服电机的电流由**负载力矩**决定,而不是由角度决定:

```
I ≈ (τ_load + τ_friction + τ_gravity) / (Kt × 效率)

τ_gravity 与角度有关(三角函数),但它同时依赖载荷质量、力臂、机体姿态
τ_load   完全与角度无关
```

同一个电流值可以对应多个 **(角度, 负载)** 组合。要唯一确定角度必须已知负载,要已知负载必须已知整机动力学状态。这是一个**结构性欠定问题**——不是数据不够或模型太小的那种欠定,再多训练数据也无法消除。

| 情况 | 电流能否区分角度 |
|---|---|
| 台架上固定负载、固定姿态 | 可以拟合(但只在这一个工况成立) |
| 空载与满载混在一起 | 不能 |
| 上坡/下坡/不同地面摩擦 | 不能 |
| 温度变化导致摩擦与电阻变化 | 不能 |

**结论(工程推论,有明确物理依据)**:若模型输入只有(命令脉宽、电流、电压),那么"角度回归"在原理上不成立。这不是模型能力问题,是**输入信号里没有角度信息**。

### 2.3 那什么信号里有角度信息

| 信号 | 携带角度信息? | 代价 |
|---|---|---|
| 命令脉宽 | 部分(给出 θ_cmd,不给误差) | 0 |
| 电机电流 | 否(欠定) | 已有(分组采样) |
| 机体 IMU 姿态 | 间接(反映整机形变,非单关节) | 已有 |
| 步态相位 + 历史电流 | 间接(异常时可分辨) | 0 |
| 足底接触/力传感器 | 是(落地约束) | 需加传感器 |
| 关节绝对角传感器 | **是(直接测量)** | 约 10 元/关节 |
| 视觉观察自身腿部 | 是 | 占用相机与算力,视角与光照受限 |

**规律很清楚**:凡是没有直接测量角度的信号,都只能给出"整体是否异常",给不出"具体角度"。

## 3. 候选方案对比

成本按 6 条小腿估算,单位为人民币,价格是量级估算而非报价。

| 方案 | 原理 | 精度 | 成本(6 关节) | 延迟 | 开发量 | 风险 | 判定 |
|---|---|---|---|---|---|---|---|
| **A. 磁编码器** | 每个小腿轴端装 AS5600 + 磁铁,直接测角 | 优于 0.5° | 约 100-180 元(含结构) | <1ms | 小(驱动 + 标定) | 机械需留磁铁位置与同心度;I2C 走线过关节需防疲劳 | **推荐** |
| **B. 小腿换总线舵机** | 直接获得位置/力矩/温度反馈 | 0.1-0.5° | 约 300-450 元(比 MG996R 贵约 40-60 元/个) | <1ms | 小(复用总线驱动) | 单价高;器件统一但成本上升 | **推荐(与 A 二选一)** |
| **C. 物理观测器** | 用足底接触 + 机体高度 + 大腿反馈做约束求解 | ±2-5°(不稳) | 0-60 元(可能需高度传感器) | 1-5ms | 中 | 约束不足时解退化;地面不平时误差大 | 可作辅助 |
| **D. 自训练模型** | 从电流/命令/IMU 学习角度或异常 | 角度:不可行;异常:**可用** | 0 硬件 | 1-10ms | **大**(采数据、标注、训练、集成、验证、维护) | 训练真值依赖编码器(循环依赖);跨工况泛化差 | 仅用于异常检测 |
| **E. 视觉自观测** | 相机看自己腿部标记,估计关节角 | 1-5° | 约 50 元(标记与支架) | 30-60ms | 中 | 遮挡、运动模糊、光照;抢 P4 算力 | 仅作周期校验 |

### 3.1 为什么方案 D 存在"循环依赖"

训练一个回归模型需要**地面真值**(每个样本的实际角度)。而地面真值的唯一可靠来源就是编码器或传感器——**这正是你试图省掉的东西**。

可行的绕法只有三种,每种都有代价:

| 绕法 | 代价 |
|---|---|
| 临时装编码器采数据,训完拆掉 | 拆掉后退化不可控(使用中的间隙、磨损、温度都变了),且失去再校准能力 |
| 用仿真生成数据(仿真到现实迁移) | 仿真中的摩擦、间隙、形变模型不可能准确,迁移误差通常超过你想要的精度 |
| 不做回归,改做异常检测(只需正常/异常标签) | **这条可行**,不需要角度真值,见 §5 |

**所以:如果目标只是"知道它有没有坏",方案 D 成立;如果目标是"知道它在哪",方案 D 缺少必需的真值来源。**

## 4. 大腿换总线舵机:收益量化(为什么这次改动值得做)

### 4.1 扭矩余量:质量上限从 1.7kg 抬到约 2.5kg

沿用文档 07 §6.3 的算法(动态系数 2,力臂 大腿 75mm / 小腿 50mm,余量目标 1.3):

| 关节 | 原方案(MG996R ×18) | 新方案(大腿总线舵机 25 kg·cm + 小腿 MG996R) |
|---|---|---|
| 大腿允许质量 | (W/3)×0.075×2 ≤ 1.08/1.3 → **W ≤ 1.7kg** | (W/3)×0.075×2 ≤ 2.45/1.3 → W ≤ 3.85kg |
| 小腿允许质量 | W ≤ 2.54kg | W ≤ 2.54kg(未变) |
| **整机瓶颈** | **大腿 → 1.7kg** | **小腿 → 2.5kg** |

**结论**:换大腿后,新的瓶颈从大腿转移到小腿,整机质量上限提升约 **47%**。你现在 2.2kg 的基线方案从"超出余量"变成"有约 30% 余量,可行"。

### 4.2 额外收益(除了扭矩)

| 收益 | 说明 |
|---|---|
| **位置反馈** | 大腿角度直接可读,IK 的一半变成闭环,足端定位误差主要由小腿贡献 |
| **力矩可控** | 总线舵机可设最大力矩,直接保护机械与舵机(这是 MG996R 完全做不到的) |
| **过载可观测** | 可直接读到负载/电流/温度,不需要外部分流推断 |
| **受控卸力** | 总线舵机可命令"阻尼下降",而 MG996R 断电即自由落体。这条对急停后的安全性提升很大 |
| **接线简化** | 总线串接,12 个舵机只需 2-3 根线穿行,替代 12 路独立 PWM + 电源线 |
| **释放引脚与定时器** | 省下 12 个 PWM 通道(详见文档 02 的重新分配) |

### 4.3 代价与风险

| 代价 | 缓解 |
|---|---|
| 单价上升(25 kg·cm 总线舵机约 60-120 元 vs MG996R 约 15 元) | 只用在受力最大的大腿与髋关节,小腿保留 MG996R,是性价比最优的组合 |
| 混用两种舵机(总线 + PWM) | 驱动层抽象为统一的 `joint_t`,上层不感知差异(文档 04 §6) |
| 总线是单点:一条线坏了影响多个关节 | 分成 2-3 条总线(左右或每 2 腿一条),把单点故障范围缩小 |
| 总线通信可能阻塞实时回路 | **总线读写必须在独立任务异步进行,禁止阻塞 250Hz 步态解算**(硬性规则) |
| 工作电压可能不同(部分总线舵机为 12V 型号) | 按型号核对;若为 12V 型号,M3 需增加一路舵机电压轨(见文档 07 §4.1) |

## 5. 推荐方案:分层解决,而不是让模型代替传感器

### 5.1 三层结构

```
第 1 层(必需,决定精度)
  大腿 + 髋:总线舵机,位置直接可读     -> 闭环主干
  小腿:MG996R 命令值 + 标定表           -> 开环,已知误差上界 0.5-2 度

第 2 层(可选,决定精度上限;按预算二选一)
  A) 小腿加 AS5600 磁编码器(约 10 元/关节)   -> 小腿也变成闭环
  B) 小腿也换总线舵机                          -> 器件统一,反馈最全

第 3 层(推荐做,决定可靠性)
  异常检测模型:输入电流/IMU/步态相位/命令,输出"正常/卡死/失步/断线"
  这是模型真正擅长的地方,而且不需要角度真值
```

### 5.2 第 3 层为什么值得做(即使不加编码器)

不加编码器时,小腿的实际不确定度来源是:死区 0.45° + 齿轮间隙(典型 0.5-1.5°)+ 负载形变 + 电位器漂移。合计约 1-3°,对应足端误差:

```
小腿长 100mm,角度误差 1 度 -> 足端误差约 1.75mm
角度误差 3 度               -> 足端误差约 5.2mm
```

对一般行走,5mm 的足端误差可以接受(地面不平度往往更大)。**所以小腿不装编码器也能走路**,这是不开传感器的前提条件——但一旦要做精确落点、爬台阶或长期可靠性诊断,就必须补上。

### 5.3 异常检测的可行输入与判据

| 异常 | 可观测特征 | 检测难度 |
|---|---|---|
| 舵机卡死/堵转 | 该组电流持续高于阈值 + 步态相位在动 + 机体姿态无变化 | 低(阈值即可,甚至不需要模型) |
| 齿轮脱扣/打滑 | 电流正常但姿态响应与命令不符(机体高度或倾角不符预期) | 中 |
| 舵机断线/无响应 | 该组电流异常低 + PWM 正常输出 | 低 |
| 电位器漂移 | 长期统计:相同命令下的姿态偏移缓慢累积 | 中(需要基线模型) |
| 电池跌落导致失力 | 母线电压低 + 多组电流同时异常 | 低 |

**重要的工程判断**:上表前 5 行里,有 3 行用**阈值 + 逻辑**就能解决,不需要机器学习。真正需要模型的是"齿轮脱扣"与"电位器漂移"这类**多信号弱特征**问题。

所以建议的实现顺序是:

1. 先用**阈值 + 状态机**实现基础异常检测(1-2 天工作量)
2. 采集正常运行数据,建立基线
3. 当阈值方案误报/漏报明显时,再引入模型(此时你已经有标注数据了)

**不要一开始就上模型**:没有基线数据,你既无法训练也无法评估效果。

## 6. 如果你仍想走纯模型路线:怎样把风险降到最低

这个方向不是不能做,但它应该被设计成**增量增强**,而不是**替代传感器**。三条约束必须接受:

| 约束 | 含义 |
|---|---|
| 模型输出不是绝对角度 | 只能输出"偏差估计 + 置信度",且必须在异常工况下失效时要能自报"我不可信" |
| 必须有对照真值才能验收 | 至少在一个关节上装一颗编码器作为"黄金参考",否则你无法证明模型准不准 |
| 不能进入安全链路 | 安全保护(过流、姿态、失稳)必须由阈值与硬件完成,模型只做辅助诊断 |

推荐的落法(如果你要体现"模型判位"这个能力):

1. 在 **1 个**小腿关节装编码器作为黄金参考(约 10 元),而不是 6 个
2. 采集多工况数据(空载/负重、不同角度、不同姿态、冷热)
3. 模型输出:角度偏差估计 + 异常概率
4. 用黄金参考验收:看偏差估计的误差分布,以及异常检测的误报/漏报率
5. 其余 5 个关节用同一模型推理,定期用黄金参考关节交叉校验

这样既保留了"模型判位"的能力与展示价值,又不把安全与精度押在它身上,而且开发成本可控。

## 7. 实验卡:EC-09 小腿位置方案对比与标定

日期:待执行 | 对应风险:R13、R16、新增 R17(小腿位置不可观测)

**要消除的不确定性**

小腿关节在不加传感器时,实际角度误差到底有多大;加编码器能改善多少;足端定位误差是否足以支撑步态。当前证据等级:估算(1-3° 与 1.75-5.2mm 都来自推算,未实测)。

**前置条件**

- 环境:1-2 条完整腿(含 MG996R × 1-2、机械结构件);磁性编码器(AS5600 或同类)× 2;角度基准(数字角度计或第二颗编码器);砝码与夹具
- 输入:MG996R 标定表;文档 05 的逆运动学参数
- 前置状态:能用 F407 输出稳定的 50Hz PWM,并能读回编码器角度

**执行命令**

```
# 1. 编码器与角度基准对齐,建立真值(静态,多次重复)
# 2. 命令扫过 ±45 度 行程,每个角度点记录:命令角 / 编码器角 / 分组电流
# 3. 空载与负重(50%、100% 额定扭矩)各做一轮
# 4. 反复往返 200 次,观察迟滞与间隙的累积表现
# 5. 用第 2-4 步数据评估:误差分布、迟滞宽度、是否可建立补偿表
#    人工:每次改变负载都要重新记录,不要混在一个数据集里
```

**要保存的 log**

- 保存方式:`logs/2026-xx-xx-ec09-tibia-position/`
- 要记录:命令角-实际角误差分布(均值/标准差/最大)、迟滞宽度、间隙量、电流与误差的相关性、温度
- 失败时额外保存:出现失步或卡死的原始时间序列

**成功 / 失败 / 停止条件**

- 成功:空载误差 ≤2°,负重误差 ≤3°,迟滞 ≤1.5°;据此得出的足端误差 ≤5mm
- 失败:任何工况下误差 >5°,或出现明显失步
- 停止:舵机明显发热或出现异响,立即停止

**结果如何改变下一步**

- 若成功(误差在可接受范围):小腿保留 MG996R,不加编码器,直接进入步态调试;**R17 关闭**
- 若失败或需要精确落点:按方案 A(编码器)或方案 B(小腿也换总线舵机)二选一,更新文档 02/07
- 无论结果:把实测误差写入文档 05 的标定章节与文档 06 的风险表

## 8. 结论与需要你确认的事项

### 8.1 结论

1. **大腿换总线舵机:做。** 它把整机质量上限从 1.7kg 提到约 2.5kg,顺带带来位置反馈、力矩限制与受控卸力,是当前性价比最高的一次硬件改动。
2. **小腿用模型判断位置:不要作为位置来源,改作异常检测。** 位置回归在原理上欠定(§2.2),而异常检测确实可行且有价值(§5.2)。
3. **小腿位置若确实需要精确值,优先加 10 元级的磁编码器**,或者把小腿也换成同系列总线舵机。两者都比训练模型便宜、快、可靠。
4. **不做任何补充时,小腿的开环误差预计 1-3°(足端 2-5mm),一般行走可接受**——这是必须先实测确认的前提(EC-09)。

### 8.2 需要你确认的事项

## 0. 使用说明与状态标记

本表是**接口配置草案**。三类内容要分开看:

| 状态 | 含义 | 是否可直接画原理图 |
|---|---|---|
| 已锁定 | 引脚分配已完成冲突检查,参数确定 | 可以 |
| 待定 | 功能已确定,具体引脚需按模组 datasheet 复核 | 不可,需先复核 |
| 待选 | 方案有多个分支,需先做选型决策(见文档 01 第 9 节) | 不可 |

**电气总原则**:所有节点数字 IO 均为 3.3V CMOS。跨板连接线建议 ≤20cm 并串 22-33Ω 电阻做阻抗匹配;SPI 高速线需等长且包地。

### 2.2 舵机接口(2026-09-27 改版:髋+大腿走总线,小腿走 PWM)

新的分配:**髋与大腿共 12 个关节改用总线舵机(带位置反馈),小腿 6 个关节保留 MG996R PWM**。这一改动带来两个直接结果:总线舵机有位置反馈与力矩限制,且只占 6 个 PWM 通道。

#### 2.2.1 小腿 PWM(6 路,已锁定)

| 腿号 | 关节 | 功能名 | 引脚 | 定时器通道 | 定时器 |
|---|---|---|---|---|---|
| L1 | 小腿 tibia | TIBIA_1 | PE9 | TIM1_CH1 | TIM1(高级,带 BKIN) |
| L2 | 小腿 tibia | TIBIA_2 | PE11 | TIM1_CH2 | TIM1 |
| L3 | 小腿 tibia | TIBIA_3 | PE13 | TIM1_CH3 | TIM1 |
| L4 | 小腿 tibia | TIBIA_4 | PE14 | TIM1_CH4 | TIM1 |
| L5 | 小腿 tibia | TIBIA_5 | PC8 | TIM8_CH3 | TIM8(高级,带 BKIN) |
| L6 | 小腿 tibia | TIBIA_6 | PC9 | TIM8_CH4 | TIM8 |

**设计要点**:6 路小腿 PWM 全部挂在两个**高级定时器**上,所以急停的 BKIN 硬件关断对全部小腿有效。TIM8 只用 CH3/CH4,把 CH1/CH2 对应的 PC6/PC7 让给了 USART6(总线 B)。

**释放出来的资源**:TIM4、TIM5、TIM9 整体空闲;引脚 PD12-PD15、PA0-PA3、PE5、PE6 全部释放,可用于 ADC 扩展、足底接触检测或后续升级。

#### 2.2.2 总线舵机接口(髋 + 大腿,12 个关节)

总线舵机是**半双工单线**串行总线,可串接多个舵机。为避免"一条线坏了影响 12 个关节",基线拆成 **3 条总线(每 2 条腿一组)**:

| 总线 | 覆盖关节 | UART | TX | RX | 方向控制(DE) |
|---|---|---|---|---|---|
| BUS_A | L1 + L2 的髋与大腿(4 个) | UART4 | PC10 | PC11 | PD8 |
| BUS_B | L3 + L4 的髋与大腿(4 个) | USART6 | PC6 | PC7 | PD9 |
| BUS_C | L5 + L6 的髋与大腿(4 个) | UART5 | PC12 | PD2 | PD10 |

**三条总线的好处**:任一条总线故障,最多影响 2 条腿的髋与大腿,机器人有可能用剩余 4 条腿维持站立姿态并安全趴下,而不是整体瘫掉。

**接线要点(按所选舵机型号的官方参考电路实现)**

1. 半双工总线通常把 TX 与 RX 通过电阻耦合到同一根信号线;若模组自带方向控制则直连,否则用 DE 引脚加三态缓冲
2. 总线信号线串 22-100Ω 电阻,降低反射
3. 舵机动力线(6-12V)与信号线分开走,不要并行贴在一起
4. 总线串接顺序建议**沿机械链**:M3 → 髋 → 大腿 → 返回,线束长度最短
5. 每个舵机分支预留 100nF 就近去耦

**两条硬性固件规则(采纳入文档 04)**

- 总线读写必须在**独立任务**中异步进行,**禁止阻塞 250Hz 步态解算**
- 总线超时要可恢复:某个舵机无响应时,不许卡死整个总线循环,超时后标记该关节失效并继续

> 小腿仍是 **MG996R**(模拟舵机、无位置回读),所以 6 路 PWM 按 50Hz 固定工作,位置精度依赖标定表与 EC-09 的实测结论(见文档 08)。

**PWM 参数(小腿 MG996R)**

| 参数 | 值 | 计算依据 |
|---|---|---|
| 定时器时钟 | 168 MHz(APB2 定时器) / 84 MHz(APB1 定时器) | F407 定时器时钟为 APB 时钟的 2 倍 |
| 预分频 | 使计数器为 1 MHz | 168-1 或 84-1 |
| ARR | 19999(50Hz) | 1MHz / 50Hz = 20000 计数 |
| 脉宽范围 | 500-2500us | MG996R 标称范围;实际安全范围由标定决定 |
| 中位 | 1500us | 每关节有独立中位偏移校准值 |
| 死区 | 约 5us | MG996R 规格书,决定角度分辨率上限 |
| 灵敏度 | 约 **0.09°/µs**(2000µs 对应约 180°行程) | 标定时实测修正 |
| 有效角度分辨率(估算) | 约 **0.5°**(受 5µs 死区限制) | 比死区更细的指令没有意义,IK 输出应先量化 |
| 未来数字舵机 | ARR=3999 → 250Hz | **仅在换数字舵机时启用**,需同步改固件与线束参数 |

> **无位置反馈的影响**:MG996R 没有对外位置回读,所以小腿的到位判断只能靠"电流正常 + 姿态一致"间接保证,`TELEM_STATUS.servo_ok` 表达的是电流健康度而非位置。髋与大腿改用总线舵机后,这一限制只作用于 6 个小腿关节,整机足端定位误差主要由小腿贡献(详见文档 08)。

### 2.4 安全与电源控制(已锁定)

| 功能 | 引脚 | 配置 | 说明 |
|---|---|---|---|
| 急停按钮输入 | PE2 | EXTI2,常闭回路,内部上拉 | 断线即触发(失效安全) |
| 急停硬件输出(TIM1) | PE15 | TIM1_BKIN (AF1) | 触发即关闭 TIM1 全部 PWM 输出 |
| 急停硬件输出(TIM8) | PB3 | TIM8_BKIN (AF3) | 触发即关闭 TIM8 全部 PWM 输出 |
| 舵机电源使能 | PE3 | GPIO 输出(低有效) | 经 J2 送到 M3,与急停回路**硬件相与**后才驱动舵机母线 MOS |
| 急停状态回读 | PE4 | GPIO 输入 | 从 M3 读回急停回路状态,供固件上报遥测 |
| M1 电源使能 | PE7 | GPIO 输出 | 经 M3 控制 M1 感知模块上电 |
| M1 复位 | PE8 | GPIO 输出(可选) | 经 J2/M3 拉低 P4 复位(视觉域死机时恢复) |
| 电源保持自锁 | PC13 | GPIO 输出 | 软启动后维持主 MOS 导通(可选) |
| 舵机分组电流 | PB6/PB7 | I2C1 | M3 上的 3× INA226(经 J2 走 I2C),用于堵转检测 |

> **MG996R 的过流保护是必需项,不是可选项**:MG996R 在卡死时会持续堵转(约 2.5A)并快速发热,而它没有位置反馈,固件无法从位置判断异常。只能靠分组电流检测 + 关节限位 + 姿态一致性判据共同判断。

> **BKIN 生效前提**:使用 PB3 作 TIM8_BKIN 必须关闭 JTAG-DP(保留 SWD)。这是运行时的 AF 配置,不涉及 Option Bytes 写入。PE15 作 TIM1_BKIN 无此限制。
>
> **失效安全设计**:急停按钮用常闭回路。按钮被按下、线缆断裂、接插件脱落三种情况都会触发急停,而不是只有按下才触发。

| SWCLK | PA14 | 必须保留 |

| BOOT0 | - | 引出跳线(建议 10k 下拉) |
| HSE | PH0 / PH1 | 8 MHz 晶振,用于 PLL 得 168MHz |

### 2.6 引脚占用总检(冲突检查结果)

| 外设 | 占用引脚 | 状态 |
|---|---|---|
| TIM1 (4ch) | PE9, PE11, PE13, PE14, + BKIN PE15 → 小腿 L1-L4 | 无冲突 |
| TIM8 (2ch) | PC8, PC9, + BKIN PB3 → 小腿 L5-L6(CH1/CH2 让给 USART6) | 无冲突(需关 JTAG-DP) |
| UART4 / USART6 / UART5 | PC10/PC11、PC6/PC7、PC12/PD2 → 三条总线舵机 | 无冲突 |
| TIM4 / TIM5 / TIM9 | 已释放(18 路 PWM 降为 6 路) | 资源空闲 |
| 释放引脚 | PD12-PD15、PA0-PA3、PE5/PE6、PE10/PE12 | 可用于 ADC 扩展或足底接触检测 |
| TIM3 (2ch) | PB0, PB1 | 仅蜂鸣器与状态灯 |
| SPI1 | PA4-PA7 | 无冲突 |
| SPI2 | PB12-PB15 | 无冲突 |
| USART1 | PA9, PA10 | 无冲突 |
| USART3 | PB10, PB11 | 无冲突 |
| USART2 | PD5, PD6 | 无冲突 |
| I2C1 | PB6, PB7 | 无冲突 |
| ADC1/2/3 | PC0-PC3 | 无冲突 |
| SWD | PA13, PA14 | 保留 |

**结论:改用 6 路 PWM + 3 条总线后,引脚占用从 58 个降到约 49 个,可用扩展位明显增多(PD12-PD15、PA0-PA3、PE5/PE6 等整组空闲)。**

### 3.2 分配时必须避开/注意

| 类别 | 说明 |
|---|---|
| 模组内置 Flash / PSRAM 占用脚 | 绝对不可外接,以模组 datasheet 的"不可用 GPIO 列表"为准 |
| Strapping 引脚 | 上电时序决定启动模式,外接器件不得在复位期间拉错电平 |
| USB 专用脚 | 若走 USB-Serial-JTAG,注意与 GPIO 的复用关系 |
| 模拟输入 | P4 无 ADC 需求(本项目模拟量都在 STM32),无需预留 |
| 电源域 | M1 本地 3V3(≥3A,给 P4+C5+外设),输入取 M3 的 5V_AUX;P4 电源脚就近放 10uF + 100nF |

### 3.3 供电与复位

| 项 | 配置 |
|---|---|
| 供电 | 来自 M3 的 5V_AUX(J3),M1 本地降压到 3V3;上电使能由 STM32 的 PE7 经 M3 控制 |
| 复位 | 引出 EN 按键 + 10k 上拉 + 1uF 到地;并可由 C5 的 GPIO 拉低复位(**预留,便于 P4 死机时远程恢复**) |
| 启动模式 | 引出 BOOT 跳线/按键 |
| 电流 | 估算 3V3 峰值 1.2A(含摄像头),Buck 需留 50% 余量 |

## 4. ESP32-C5 接口配置(网络与射频感知)

> 状态:**待定**。C5 的 GPIO 数量少于 P4,且 Wi-Fi 6 双频 + 802.15.4 的射频口占用固定,SPI 从机与 CSI 能力必须按所用 ESP-IDF 版本核对。下表定义功能与约束。

### 4.1 对外接口

| 功能 | 接口类型 | 参数 | 约束与备注 |
|---|---|---|---|

### 4.2 供电与射频注意事项

| 项 | 配置 |

## 6. 板间连接器(已按三模块决策改版)

按 2026-09-27 的模块划分决策,P4 与 C5 同处 M1,所以不再有"视觉板↔网络板"的连接器;**6 路 PWM 与 3 条总线**改为跨板送到 M3。

| 连接器 | 位置 | 规模 | 关键信号 |
|---|---|---|---|
| J1 | M1 感知 ↔ M2 控制 | 2×6 (12 pin) | UART(2)、P4_IRQ、P4_READY、P4_RST、GND×4;不传电源 |
| J2 | M2 控制 ↔ M3 电源驱动 | 2×18(34-36 pin,**比原方案少 8 针**) | **6 路小腿 PWM**、**3 条总线舵机(各 TX/RX/DE)**、SERVO_PWR_EN、ESTOP_STATUS、电压采样×2、I2C×2、5V_AUX×3、GND×8、预留 CAN×2 |
| J3 | M1 感知 ↔ M3 电源驱动 | 2×4 (7-8 pin) | 5V_AUX×3、GND×4、PWR_EN_M1 |
| J4 | M3 对外舵机插座 | 18× 3pin | 按 A/B/C 三组各 6 路:信号 / 6V / GND |
| J5 | M3 对外人机接口 | — | 急停按钮(常闭)、主开关、充电口、状态指示灯 |

**逐条定义、引脚编号、线束规范与接地策略见文档 07。**

连接器设计原则:

- 每个信号组之间夹一根 GND(M2↔M3 的 PWM 与总线信号尤其重要)
- 功率针与信号针分区排布,插拔防呆(keying)
- J2 上预留的 UART4 与 CAN 引脚**必须真的引出到针脚**,不要只在图纸上标注,否则升级时无路可走

## 7. 电气规格汇总

| 参数 | 值 | 备注 |
|---|---|---|
| 数字逻辑电平 | 3.3V CMOS | 三节点一致,无需电平转换 |
| 数字 IO 耐压 | 3.6V 上限 | 禁止直接接 5V 信号(除标注 5V 容忍的脚) |
| 舵机信号电平 | 3.3V 进 M3 → **5V 输出**(74HCT245 缓冲) | MG996R 部分批次的高电平门限接近 3.0V,缓冲后消除偶发不动作 |
| 舵机电源(小腿 PWM) | **6.0-6.5V / 10-12A** | MG996R 额定 4.8-7.2V;3S 必须降压,2S 满电 8.4V 不可直供 |
| 舵机电源(髋/大腿总线) | **按型号定**(常见 6-8.4V 或 12V) | 12 个总线舵机功率通常大于小腿,**必须按选定型号核对电压上限**;若为 12V 型号不能直用满电 3S(12.6V) |
| 舵机母线储能 | ≥4700µF 低 ESR | 18 台 MG996R 的启动浪涌 |
| 系统电源 | 5V_AUX(4A)→ M1/M2 各自本地 3.3V | M3 统一出 5V,各模块独立稳压 |
| 板间 UART 电平 | 3.3V,串 33Ω | 线长 ≤20cm |
| SPI 速率 | STM32↔IMU 10MHz;P4↔C5 20-40MHz | 高速线需包地并控制阻抗 |
| 接地策略 | 星形单点,**汇合点在 M3**,舵机回流走专用宽铜皮 | 避免舵机电流流过任何 MCU 模块的地 |
| 上电浪涌 | 需软启动限流 | 4700µF 在 12.6V 约 0.37J,无限流会触发电池保护 |

## 8. 本文件的待验证清单(打样前必须关闭)

| # | 待验证项 | 验证方法 | 影响 |
|---|---|---|---|
| 1 | ESP32-P4 模组的可用 GPIO 列表与 MIPI-CSI/DSI 引脚占用 | 查模组 datasheet 与 IO MUX 表 | 决定 M1 引脚可行性与 PCB 布局(摄像头与屏同时占用 MIPI) |
